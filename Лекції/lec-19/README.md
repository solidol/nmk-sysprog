# Обробка файлів ч.1. Бібліотека STDIO

[Перелік лекцій](README.md)



## Загальна характеристика STDIO

Бібліотека **STDIO** (`<cstdio>`) — це стандартний засіб мови C для роботи з потоками вводу/виводу, який повністю підтримується в C++.  

У контексті файлів STDIO забезпечує:
- роботу з текстовими та бінарними файлами
- буферизований ввід/вивід
- універсальний інтерфейс доступу до різних джерел даних (файли, консоль, мережеві потоки — через перенаправлення)

У STDIO файл розглядається як **потік даних (stream)** — послідовність байтів, яка може:
- читатися (input stream)
- записуватися (output stream)
- або виконувати обидві операції

### Основні стандартні потоки:
- `stdin` — стандартний ввід
- `stdout` — стандартний вивід
- `stderr` — потік помилок

Файлові потоки представлені типом:

`FILE*`


Це структура, яка містить:
- позицію у файлі
- буфер
- режим доступу
- стан помилок


Однією з ключових особливостей STDIO є **буферизація**.

Буфер — це область пам'яті, в якій тимчасово зберігаються дані перед:
- записом у файл
- або після читання з файлу

### Типи буферизації:

| Тип | Опис |
|-----|------|
| Повна (fully buffered) | запис/читання відбувається блоками |
| Рядкова (line buffered) | дані передаються після `\n` |
| Без буфера (unbuffered) | кожна операція одразу записується |

Переваги:
- значне підвищення продуктивності
- зменшення кількості звернень до диска

Недоліки:
- можливість втрати даних при аварійному завершенні програми

---

## Відкриття файлу

Функція відкриття створює зв'язок між файлом і потоком у програмі.

FILE\* fopen(const char\* filename, const char\* mode);


### Важливі аспекти:
- якщо файл не відкрито → повертається `NULL`
- режим визначає дозволені операції
- один файл може бути відкритий кілька разів (з різними режимами)

---

## Режими доступу до файлів

| Режим | Опис | Поведінка |
|------|------|----------|
| `r`  | тільки читання | файл має існувати |
| `w`  | тільки запис | створює новий або очищає існуючий |
| `a`  | дозапис | запис у кінець файлу |
| `r+` | читання + запис | файл має існувати |
| `w+` | читання + запис | очищає файл |
| `a+` | читання + дозапис | запис тільки в кінець |
| `rb` | читання (бінарний режим) | без перетворень |
| `wb` | запис (бінарний режим) | створює/очищає |
| `ab` | дозапис (бінарний) | додає в кінець |
| `rb+` / `r+b` | читання + запис (бінарний) | файл має існувати |
| `wb+` / `w+b` | читання + запис (бінарний) | очищає файл |
| `ab+` / `a+b` | читання + дозапис (бінарний) | запис у кінець |

---

## Текстовий та бінарний режим

Текстовий режим:
- дані інтерпретуються як текст
- можливі перетворення:
  - `\n` → `\r\n` (Windows)
- зручно для читання людиною

Бінарний режим:
- дані читаються "як є"
- без змін і перетворень
- використовується для:
  - структур
  - зображень
  - виконуваних файлів


## Закриття файлу

fclose(FILE\* file);


Відбувається:
- очищення буфера (flush)
- звільнення ресурсів
- завершення зв’язку з файлом

⚠️ Якщо не закрити файл:
- можливі витоки ресурсів
- частина даних може не записатися

---

## Позиція у файлі

Кожен відкритий файл має **поточну позицію (file position indicator)**.

Основні операції:
- переміщення позиції
- отримання позиції
- повернення на початок

Значення:
- дозволяє читати/писати не послідовно
- використовується для випадкового доступу (random access)

---

### Кінець файлу (EOF)

EOF (End Of File) — спеціальний стан, що означає:
- дані закінчилися
- подальше читання неможливе


> EOF встановлюється **після невдалої спроби читання**, а не до неї.

---

## Обробка помилок

STDIO використовує кілька механізмів:

- перевірка `NULL` після `fopen`
- функції:
  - `ferror()` — перевірка помилки
  - `feof()` — перевірка кінця файлу
  - `perror()` — вивід повідомлення

---

## Безпека та обмеження

Недоліки STDIO:
- відсутність типобезпеки
- ручне керування ресурсами
- ризик переповнення буфера
- складніша робота з рядками

Потенційні проблеми:
- неправильний режим відкриття
- забутий `fclose`
- неправильна робота з EOF
- читання невірного формату

---

## Порівняння з C++ потоками

| Критерій | STDIO | C++ (iostream) |
|----------|------|----------------|
| Рівень | низький | високий |
| Безпека | низька | висока |
| Швидкість | висока | трохи нижча |
| Зручність | середня | висока |
| Типізація | відсутня | сильна |

---

## Коли використовувати STDIO

STDIO доцільно застосовувати коли:
- потрібна максимальна продуктивність
- робота з бінарними даними
- сумісність з C-кодом
- системне або вбудоване програмування

---

##Висновки

- STDIO — це базовий, ефективний механізм роботи з файлами
- ключовим елементом є `FILE*`
- важливу роль відіграє буферизація
- необхідно уважно працювати з режимами відкриття
- сучасний C++ пропонує більш безпечні альтернативи, але STDIO залишається актуальним

## Приклади

### запис рядків і чисел у файл

```cpp
#include <cstdio>

int main() {
    FILE* file = fopen("text.txt", "w");

    if (!file) {
        perror("Помилка відкриття файлу");
        return 1;
    }

    fprintf(file, "Ім'я: %s\n", "Іван");
    fprintf(file, "Вік: %d\n", 20);
    fprintf(file, "Середній бал: %.2f\n", 89.75);

    fclose(file);
    return 0;
}
```

### Читання з текстового файлу


```cpp
#include <cstdio>

int main() {
    FILE* file = fopen("text.txt", "r");

    if (!file) {
        perror("Помилка відкриття файлу");
        return 1;
    }

    char name[50];
    int age;
    double grade;

    fscanf(file, "Ім'я: %s\n", name);
    fscanf(file, "Вік: %d\n", &age);
    fscanf(file, "Середній_бал: %lf\n", &grade);

    printf("Прочитано:\n");
    printf("Ім'я: %s\nВік: %d\nБал: %.2f\n", name, age, grade);

    fclose(file);
    return 0;
}
```

### Читання текстового файлу порядково
```cpp
#include <cstdio>

int main() {
    FILE* file = fopen("text.txt", "r");

    if (!file) return 1;

    char buffer[100];

    while (fgets(buffer, sizeof(buffer), file)) {
        printf("%s", buffer);
    }

    fclose(file);
    return 0;
}
```

### Запис у бінарний файл

```cpp
#include <cstdio>

struct Student {
    char name[50];
    int age;
    double grade;
};

int main() {
    FILE* file = fopen("students.dat", "wb");

    if (!file) {
        perror("Помилка відкриття файлу");
        return 1;
    }

    Student s1 = {"Іван", 20, 90.5};
    Student s2 = {"Марія", 21, 95.0};

    fwrite(&s1, sizeof(Student), 1, file);
    fwrite(&s2, sizeof(Student), 1, file);

    fclose(file);
    return 0;
}
```

### Читання з бінарного файлу
```cpp
#include <cstdio>

struct Student {
    char name[50];
    int age;
    double grade;
};

int main() {
    FILE* file = fopen("students.dat", "rb");

    if (!file) {
        perror("Помилка відкриття файлу");
        return 1;
    }

    Student s;

    while (fread(&s, sizeof(Student), 1, file) == 1) {
        printf("Ім'я: %s, Вік: %d, Бал: %.2f\n", s.name, s.age, s.grade);
    }

    fclose(file);
    return 0;
}
```
### Копіювання файлу (бінарний режим)
```cpp
#include <cstdio>

int main() {
    FILE* src = fopen("input.bin", "rb");
    FILE* dst = fopen("output.bin", "wb");

    if (!src || !dst) {
        perror("Помилка відкриття файлу");
        return 1;
    }

    char buffer[1024];
    size_t bytes;

    while ((bytes = fread(buffer, 1, sizeof(buffer), src)) > 0) {
        fwrite(buffer, 1, bytes, dst);
    }

    fclose(src);
    fclose(dst);

    return 0;
}
```

### Додавання даних у текстовий файл
```cpp
#include <cstdio>

int main() {

    fprintf(file, "Новий запис у журналі\n");

    fclose(file);
    return 0;
}
```
### Додавання даних у бінарний файл
```cpp
#include <cstdio>

struct Number {
    int value;
};

int main() {
    FILE* file = fopen("numbers.dat", "ab");

    if (!file) return 1;

    Number n = {100};

    fwrite(&n, sizeof(Number), 1, file);

    fclose(file);
    return 0;
}
```
### Визначення розміру файлу
```cpp
#include <cstdio>

int main() {
    FILE* file = fopen("students.dat", "rb");

    if (!file) return 1;

    fseek(file, 0, SEEK_END);
    long size = ftell(file);

    printf("Розмір файлу: %ld байт\n", size);

    fclose(file);
    return 0;
}
```
